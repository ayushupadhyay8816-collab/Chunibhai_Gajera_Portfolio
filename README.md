# Chunibhai Gajera Portfolio Website
Responsive student portfolio made with HTML5 and external CSS3.

## Files
- `index.html` — page content
- `style.css` — external styles, responsive layout, cards, table and form
- `.nojekyll` — GitHub Pages helper

## Before submitting
1. Replace student-detail placeholders in the footer.
2. Replace `your-email@example.com` in the contact form if desired.
3. The sample form opens an email app; it does not store messages.
4. The portrait is loaded from the official profile site, so internet access is required.
5. Formal school/college qualifications were not listed in the official biography; this page does not invent them.

## GitHub Pages
1. Create a public repository, e.g. `chunibhai-gajera-portfolio`.
2. Upload these files to the repository root.
3. Open Settings → Pages.
4. Choose Source: Deploy from a branch; Branch: `main`; Folder: `/(root)`.
5. Click Save, wait for deployment, and open the link shown on the Pages page.
6. Typical URL: `https://YOUR-USERNAME.github.io/chunibhai-gajera-portfolio/`
